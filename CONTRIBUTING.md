# Contributing

Bug reports and pull requests are welcome.

When reporting an importer issue, include:

- Blender version and operating system
- Naraka NR capture format/version if known
- The selected group ID, if one was entered
- Blender console output or a short error message

Do not upload game captures, extracted textures, or other copyrighted assets to the repository. Use a small synthetic test case or describe the affected `.nr` structure instead.
